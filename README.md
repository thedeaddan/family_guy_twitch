# Twitch Extra Player — Пользовательская инструкция

Компактный userscript для **Tampermonkey**, который добавляет **дополнительный видео-плеер** по **центру** страницы **сразу под блоком «Сведения о трансляции»** на страницах Twitch.
Плеер открывается во встроенном `iframe`; если встраивание заблокировано — есть кнопка «Открыть в окне».

## Что вы получите

* Один дополнительный плеер **под «Сведения о трансляции»**.
* Компактный центрированный блок (по умолчанию ширина `clamp(480px, 60vw, 900px)`).
* Две кнопки:

  * **Открыть в окне** — открывает видео в новой вкладке.
  * **Свернуть** — скрывает/показывает плеер.

> Управление сезонами/сериями — **внутри самого плеера**. В скрипте дополнительных селекторов нет.

---

## Требования

* Компьютерный браузер: Chrome, Edge, Firefox, Я.Браузер (настольные версии).
* Расширение-менеджер userscripts: **Tampermonkey** (рекомендуется).
  Подойдут и аналоги (Violentmonkey/Greasemonkey), но проверялось с Tampermonkey.

---

## Установка (3 шага)

1. **Установите Tampermonkey** из магазина расширений вашего браузера.
2. Откройте ссылку на скрипт:

   ```
   https://raw.githubusercontent.com/thedeaddan/family_guy_twitch/main/twitch-extra-player.user.js
   ```

   > Замените `thedeaddan/family_guy_twitch` на путь вашего GitHub. На странице Raw Tampermonkey предложит «Установить».
3. Нажмите **Install** / **Установить**.

Готово. Перейдите на канал на Twitch: `https://www.twitch.tv/<имя_канала>` — ниже блока «Сведения о трансляции» появится компактный плеер.

## Обновление

* Если вы установили скрипт по «сырой» (Raw) ссылке GitHub, Tampermonkey обычно **сам проверяет обновления**.
* Обновить вручную: откройте ту же Raw-ссылку → **Reinstall** / **Update**.

---

## Использование

* Плеер появляется **под** секцией «Сведения о трансляции».
* Кнопки:

  * **Открыть в окне** — полезно, если встроенный `iframe` не загрузился из-за ограничений.
  * **Свернуть** — убирает плеер, чтобы не мешал.

---

## Известные ограничения

1. **Политика безопасности (CSP) Twitch** или сайт источника может **запретить встраивание**.
   В таком случае `iframe` не загрузится — используйте **«Открыть в окне»**.

2. Twitch — SPA (страница без полной перезагрузки). Скрипт отслеживает переходы и **сам восстанавливает** плеер; если вдруг не появился — обновите страницу.

3. Мобильные браузеры и мобильный Twitch могут работать иначе; скрипт рассчитан на **настольные браузеры**.

## Частые вопросы (FAQ)

**Плеер не отображается / чёрный прямоугольник.**
— Скорее всего, CSP заблокировал встраивание. Нажмите **«Открыть в окне»** — видео откроется в новой вкладке.

**После перехода по Twitch-ссылкам плеер пропал.**
— Подождите 1–2 секунды: скрипт подхватит навигацию и вставит плеер снова. Если нет — выполните обновление страницы.

**Можно изменить сериал (movieId)?**
— Да. Откройте на Twitch инструменты разработчика → **Консоль** и выполните:

```js
localStorage.setItem('tep-movie-id', '3462'); // вместо 3462 укажите нужный ID
location.reload();
```

С этого момента по умолчанию будет подставляться ваш `movieId`.

> Сезон/серии выбираются внутри плеера.

**Можно изменить размер блока?**
— Да, но это правка кода. В скрипте найдите строку:

```css
#tep-center { width: clamp(480px, 60vw, 900px); }
```

и замените на нужные значения, например `clamp(420px, 50vw, 800px)` — меньше и уже.

## Удаление

* Откройте иконку **Tampermonkey** → **Dashboard** → найдите «Twitch Extra Player…» → **Disable** или **Remove**.

---

## Конфиденциальность и права

* Скрипт **ничего никуда не отправляет** и не просит дополнительных разрешений.
* Источники видео — сторонние. Соблюдайте условия использования соответствующих сервисов.

---


## Устранение неполадок

* **Конфликт расширений**: временно отключите блокировщики рекламы/приватности на `twitch.tv` и для доменов источника видео.
* **Ничего не появляется**: убедитесь, что вы на странице **канала**, а не в отдельном клипе/VOD.
* **Секция якоря переименована**: при серьёзных изменениях разметки Twitch обновите скрипт до последней версии из репозитория.
